# Case Studies

> **Space for solving problems.**

Five independently developed Product Management and Analytics case studies, originally written in Notion and published here as complete Markdown documents.

Each study focuses on a specific decision: understanding the problem, evaluating evidence, identifying root causes, comparing approaches, proposing a solution, and defining success metrics and validation tests.

## Read the case studies

| Case study | Focus |
| --- | --- |
| [Improving AI agent reliability](ai-agent-reliability.md) | Preventing plausible but incorrect financial answers through metric contracts and verification |
| [Connecting fragmented financial data](financial-data-reliability.md) | Establishing consistent data definitions and reconciling portfolio KPIs |
| [Finding and verifying business information](business-information-retrieval.md) | Retrieving the correct source documents for an analyst's question |
| [Reducing repetitive reporting work](analytics-reporting-automation.md) | Evaluating workflow automation for financial and operational reporting |
| [Evidence-led product prioritization](product-analytics-prioritization.md) | Using cohort economics and product metrics to choose what to investigate |

## How to read these

- These are **problem-solving and analytical exercises**, not all real-world deployments.
- Some studies include **synthetic data and constructed scenarios**. These are labelled in the original analyses, not presented as real product performance or live customer results.
- Proposed outcomes and metrics are **hypotheses to validate**, unless the text explicitly provides measured evidence.
- The complete reasoning, tables, formulas, limitations and source references are maintained in each document.
